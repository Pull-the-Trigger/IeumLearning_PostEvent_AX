# 맞춤 메일 초안 + 영업 전달 패키지 (custom_mail) — 담당: 소민

출석자마다 나갈 맞춤 메일 초안과, 영업으로 넘길 사람의 근거 묶음을 만듭니다.
**모든 메일은 초안이에요.** 본부장 승인 전에는 발송하지 않습니다 (06 글쓰기 기준).

## 실행 (레포 루트에서)
```
python src/custom_mail/build_mails.py              # 메일 보내는 날까지 발행된 글만 사용 (실제 상황)
python src/custom_mail/build_mails.py --as-of today # 지금 있는 글 전부 사용 (다음 행사 시연용)
```
내부에서 `src/pre_question/plan_followups.py`를 먼저 돌려 출석자별 갈래를 정합니다.

## 결과
- `out/custom_mails.csv`: 행사·사람별 메일 초안 (제목, 본문, 고른 글과 이유, 승인 방식, 글쓰기 기준 경고)
- `out/sales_handoff.csv`: 영업 담당자용 근거. 어느 행사에 왔는지, 무엇을 물었는지, 설문 응답, 지난 연락 기록, 보낸 글, 연락 기한 (07 영업팀장이 요청한 정보)

## 메일을 만드는 방식
- **문장은 사람이 정한 틀만 씁니다.** AI는 문장을 쓰지 않습니다. 사실을 지어낼 여지를 없애려고요.
- 첫 문단에 연락하는 이유를 한 문장으로 쓰고, 질문이 있으면 그 질문을 먼저 되짚습니다 (06-1, 06-4).
- 재방문자에게는 "지난 ○○에 이어 다시 참석해 주셔서 감사합니다"를 한 문장 넣습니다 (인터뷰).
- 갈래별 본문:
  - 영업: 질문 되짚기 + "담당자가 ○월 ○일까지 연락" (발송 후 영업일 3일) + 맞는 글이 있으면 1편
  - 글 안내: 질문 되짚기 + 글 1편
  - 담당자: 질문 되짚기 + "담당자가 확인 후 따로 답변" + "직접적인 답은 아니지만 참고가 될 글"
  - 설문 주제: 적어 준 주제의 글 1편 (주제에 맞는 글이 없으면 메일 생략)
- **글 고르기:** 질문마다 맞는 글을 `question_map.json`의 `article`에 짝지어 두었습니다 (검수 대상). 처음 보는 질문은 AI가 36편 중에서 고르고, 맞는 글이 없으면 "없음"으로 둡니다. **메일 보내는 날 아직 발행되지 않은 글은 쓰지 않고**, 같은 주제의 다른 글로 대신하지도 않습니다. 글 안내인데 맞는 글이 없으면 담당자 갈래로 바꿉니다.
- **글쓰기 기준 자동 검사:** 합니다체가 아닌 문장, 금지 표현(혁신적인·지금 바로 등), 느낌표 두 개 이상, 이모지, 잘못된 제품명(이음진단·부트캠프·이러닝)을 찾으면 `lint` 열에 경고를 남깁니다.
