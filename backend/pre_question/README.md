# 사전 질문 → 출석자별 후속 연락 계획 (pre_question) — 담당: 소민

출석자 한 명(한 행사)마다 어떤 메일을 보낼지 정합니다. 결과는 `out/followup_plan.csv`입니다.

## 판단 순서 (11/25 팀 결정)
1. **영업**: 아래 중 하나라도 해당하면 영업입니다 (인터뷰 10번, 넓게).
   설문 연락 희망 / 설문 도입 검토 "예"·"검토 중" / 행사장 견적·소개서·미팅 요청 / 사전 질문이 도입·과정·비용을 묻거나 상대 회사 정보가 필요함
2. **글 안내 / 담당자**: 사전 질문이 있으면 `question_map.json`의 갈래를 따릅니다.
3. **맞춤(설문 주제)**: 질문은 없지만 설문에 듣고 싶은 주제를 적은 수신 동의자에게 그 주제로 글 1편을 보냅니다.
4. **감사 메일만**: 아무것도 안 남긴 사람, 그리고 질문이 없는 미동의자입니다.

## 실행
```
python backend/pre_question/plan_followups.py
```
- 새 행사에 처음 보는 질문이 오면: AI 키가 있으면 AI가 분류하고, 없으면 담당자로 보냅니다. 끝나면 "질문 사전에 없는 질문 N건"을 알려 주니 `question_map.json`에 한 줄씩 추가하세요.
- 설문에서 연락을 원했지만 이메일이 없는 사람은 `out/followup_plan_contact_needed.csv`로 따로 나옵니다. 짐작해서 매칭하지 않습니다.
